CalJOBS Guided Mode

Task-specific walkthroughs for the ETPL screens a coordinator or provider is most likely to use.

Safety rule: CalJOBS is the State system of record. These guides are based on the March 2026 EDD CalJOBS ETPL Module Training Provider Manual and current ETPL policy. If the live screen does not match the guide, stop and validate the current process. Do not guess.
Never store here: provider passwords, FEINs, participant SSNs, participant-level wage-match workbooks, or other unnecessary PII.

Create a new provider account

Use when the organization does not already have the correct CalJOBS institution record.

  1. Training Providers → Create a Provider Account. The provider enters its FEIN directly in CalJOBS and selects Find.
  2. Check matching organizations. If the correct institution exists, stop and use the link-user workflow instead of creating a duplicate.
  3. Complete organization/user registration. Use the provider's actual legal/DBA and user-contact information.
  4. Complete the provider profile. Verify addresses, entity type, public-display and approval/accreditation fields against provider evidence.
  5. Save and submit. Treat the confirmation as an access/review step, not ETPL approval.
Link a provider user to an existing institution

Use when the institution already exists and a provider user needs access.

  1. Open Create a Provider Account and search the institution using the provider-entered FEIN.
  2. Select the correct matching organization.
  3. Complete user registration and link to the institution.
  4. If multiple plausible organizations appear, stop and have the Local ETPL Coordinator identify the correct record.
Upload provider documents

Use for provider eligibility evidence and profile documents. Keep sensitive identifiers out of tags.

  1. Menu → Document Management → Upload a Document.
  2. Select the correct document description/type.
  3. Use a neutral, useful document tag with no participant PII, SSN, password, or FEIN.
  4. Upload and verify the document appears on the Provider Profile.
Add a new training program

Use after the provider has institution access and the program facts are ready to enter.

  1. Provider Workspace → Services for Providers → Manage Institution Programs.
  2. Select Add Education or Training Program.
  3. Complete the Program Wizard from the provider's source documents, not from memory.
  4. Verify program name, training location, delivery, credential, CIP/occupation, duration, schedule, tuition/fees/books/tools/other costs, and public cost evidence.
  5. Submit for Local Board review only when the program record and evidence agree.
Initial all-student performance evidence

Use for initial-eligibility performance evidence. Do not invent outcomes for a new program.

  1. Open the Provider Profile document area.
  2. Use the applicable initial-eligibility performance form/process.
  3. Enter only supportable aggregate all-student data.
  4. For a genuinely new program without sufficient history, use the WSD25-02 new-program pathway rather than fabricating data.
Submit and review a program change

Use when an existing program's approved facts change.

  1. Open the existing program record and the applicable Program Wizard tab.
  2. Change only the field supported by the provider evidence.
  3. For cost changes, reconcile tuition, fees, books, tools, other costs, and public-facing cost evidence.
  4. Submit the change into the review queue.
  5. If the current EDD manual does not document a staff approve/deny click you see on screen, stop and validate the live staff procedure before acting.
Re-nominate provider for continued eligibility

Use to keep the provider profile current in the same calendar year as continued program review.

  1. Check Provider Review Status.
  2. Confirm Local nomination or State approval is current for the same calendar year as the program's continued-eligibility nomination.
  3. Update required provider-profile information and documents before re-nomination.
Re-approve a program for continued eligibility

Use when the program is inside its reapplication window.

  1. Confirm the program's current Subsequent Review Due Date and reapplication window.
  2. Provider uses the REAPP action when available.
  3. Provider reviews pre-populated program facts, makes supported updates, confirms the submission, and sends it to review.
  4. Local staff applies the current WSD25-02 continued-eligibility decision before State nomination.
Annual performance: aggregate method

Use only when the provider's CalJOBS reporting method is Aggregate.

  1. Provider Profile → Additional Provider Details. Verify Performance Reporting Method = Aggregate.
  2. Prepare the current EDD aggregate workbook for every reportable program.
  3. All Student means WIOA and non-WIOA students.
  4. Upload/submit through the current authorized process and verify status.
  5. If the provider wants to change reporting methods, stop. The March 2026 manual identifies reporting-method changes as EDD-controlled.
Annual performance: individual SSN method

Use only when the provider's method is Individual. SSNs stay in the authorized CalJOBS/EDD process.

  1. Verify the provider is already set to Individual reporting.
  2. Use only the authorized EDD/CalJOBS workbook/process.
  3. Never copy an SSN, workbook row, or participant-level wage-match data into Workforce Wonkery, a local tracker, or ordinary email.
  4. Record only process metadata: method, submission status, date, and unresolved error.
Design principle: Guided Mode is intentionally one task at a time. Open only the workflow you are doing. If the live screen differs from the guide, stop and verify the current process instead of opening another panel and guessing.
