Review a New Training Program

Use this when an already eligible training provider wants to add a new program to the California ETPL.

Before you act: This playbook translates current California and federal ETPL rules into an operating sequence. Official sources, the current CalJOBS workflow, and your adopted local policy control. Source check: October 7, 2026.
Use this when

The provider already has a valid ETPL provider record, but this program has never been approved.

You need to decide

Whether the new program itself meets California requirements, whether the correct Local Board owns the review, and whether a new-program performance pathway applies.

Verify against

WSD25-02, the provider's current eligibility/operating authority, current CalJOBS program procedures, and the evidence for this exact program and location.

Have these ready

Provider ETPL status · program catalog/description · credential · curriculum · program location · delivery format · cost · length · CIP/occupation mapping · operating approval for the program/location when applicable · performance data or new-program evidence.

60-second pathConfirm provider is current → confirm reviewer → verify exact program facts → evaluate applicable performance/new-program pathway → correct CalJOBS record → determine State eligibility → nominate to EDD.

1. Do not restart the provider unnecessarily

If the provider is already eligible, a new program normally requires a program review. Reopen provider-level issues only when a material change or new evidence makes provider eligibility relevant.

2. Confirm who reviews the program

Program-review responsibility generally follows the physical training location. If the provider's headquarters are elsewhere, the provider and program can have different Local Board reviewers.

3. Verify what the provider is actually offering

FieldWhat to check
Program identityName and description match the catalog and provider materials.
CredentialThe outcome is clearly described and supports the program's training purpose.
Location / deliveryPhysical, online, or hybrid delivery is accurate; any required approval covers the location/mode.
CostTotal cost components are current and do not conflict across CalJOBS, catalog, and provider documents.
LengthHours/weeks and schedule match actual program design.
CIP / occupationsCodes describe what is taught and the occupations the training actually prepares someone for.

4. Apply the correct performance path

Do not treat every new program as if it has mature historical outcomes. WSD25-02 provides a pathway for newly created programs without sufficient history. Review the evidence the directive calls for, including the provider/program's reputation and value to the workforce system, rather than inventing performance numbers or automatically failing the program.

Critical distinction: “No data yet” is not the same as “failed performance.” Document why the new-program pathway applies.

5. Check the occupational connection without turning it into a ranking contest

ETPL eligibility and local training strategy are related but different. The program record should accurately connect training to occupations, but do not use a local preferred-occupation list as an undeclared California ETPL eligibility rule.

6. Finish the Local Board review in CalJOBS

  1. Program record submitted.
  2. Evidence reviewed against WSD25-02.
  3. Corrections returned to provider when needed.
  4. State eligibility determination documented.
  5. Eligible program nominated to EDD.
  6. EDD decision tracked separately.

7. After State approval

Confirm the live CalJOBS program record reflects the approved facts. If your Local Board maintains a separate local ETPL or additional lawful local standards, apply that second decision only after the California ETPL determination.

Common mistakes

  • Assuming provider approval equals program approval.
  • Re-reviewing the entire provider for every new program.
  • Using the wrong training location or delivery mode.
  • Copying CIP/SOC codes from another program without checking curriculum.
  • Automatically denying a genuinely new program for lack of historical data.

Stop and escalate when

  • The program/location is not covered by the provider's required operating approval.
  • Costs, credential, duration, or curriculum conflict across documents.
  • You cannot determine which Local Board owns the program review.
  • The provider wants you to backdate eligibility or ignore an unresolved State requirement.
