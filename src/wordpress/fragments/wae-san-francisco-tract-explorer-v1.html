About this first San Francisco map release

Source: California Office of Environmental Health Hazard Assessment / CalEPA, CalEnviroScreen 5.0, released July 1, 2026. The browser requests the public CalEnviroScreen feature layer for San Francisco and draws the current tract geometry directly.

Phase 1 scope: six workforce-relevant condition measures and seven descriptive community-composition measures. No WIOA participant, service, case-management, or outcome records are used. No composite equity score or neighborhood ranking is produced.

Next enrichment gate: add the same validated 2020–2024 American Community Survey tract precision measures used by the Santa Cruz reference only after a San Francisco static package passes coverage, margin-of-error, geography, and public-packaging QA.
