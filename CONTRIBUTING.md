# Contributing

Thank you for helping improve Workforce Wonkery.

## Good contributions

Useful contributions include:

- corrections to public data or documentation
- accessibility improvements
- fixes to reader-facing code
- improvements to methodology documentation
- reproducibility improvements
- issues that identify unclear or outdated public information

## Please do not submit

Do not submit:

- personal information
- WIOA participant information
- credentials, API keys, tokens, or secrets
- confidential County information
- private meeting or case records
- unpublished internal material obtained from another source

## Changes

Public changes should be small, reviewable, and tied to a clear reader benefit. Explain what changed, why it changed, and how it was checked.

## Data corrections

For a data correction, include the source, source date, geography, measure, and enough detail to reproduce the correction.
