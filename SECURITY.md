# Security policy

Please do not open a public issue containing credentials, personal information, sensitive configuration, or details that would materially increase the risk of exploitation.

If you believe you found a security issue, report it privately to the Workforce Wonkery project owner through an appropriate non-public channel.

This repository is a public companion repository. Production credentials, private data, authentication secrets, and internal operational configuration should not be present here.

If sensitive information is found in this repository, treat it as an incident and rotate any affected credential rather than relying only on file removal.
