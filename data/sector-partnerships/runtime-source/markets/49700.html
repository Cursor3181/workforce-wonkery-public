Worker value

What workers should gain

Current local teacher compensation clears the Yuba-Sutter single-adult living-wage benchmark. Worker Value therefore turns on accessible preparation, conversion into stable credentialed jobs and early-career retention.

The move

Use existing residency, induction and substitute systems to select a small set of shared shortage and progression priorities rather than create a new organization.

Local operating story

The region already has pooled educator infrastructure.

Sutter County maintains substitute services for districts and charters, participates in a tri-county substitute and induction system, and operates a one-year teacher residency with Teachers College of San Joaquin. The next step is to use those systems to solve shared shortage fields and measure placement-to-hire instead of creating another educator organization.

Evidence, risks & 90-day action plan

Backbone / host: Sutter County Superintendent of Schools / Tri-County Induction and NorCal Substitute infrastructure

90-day action

0–30 days: Name district action leads for the shared shortage fields and map residency placements, substitute-to-credential routes, mentor capacity and salary progression. 31–60 days: Have participating districts co-own placement-to-hire and retention measures while keeping hiring authority local; add educator/worker feedback. 61–90 days: Run shared pathway actions only where multiple districts face the same problem, using the residency, induction and substitute infrastructure already in place.

Year-one test

Shared employer agenda; residency-to-hire outcomes; substitute-to-credential conversions; retention measures; recurring regional resources; no duplicate intermediary.

Evidence gaps

District action ownership; residency placement-to-hire; substitute-to-credential progression; recurring district/shared pathway resources beyond grant awards; early-career retention.

Stop / redesign if

Do not create a new educator organization. If no shared shortage priority exists beyond current transactional services, retain the existing services without relabeling them a mature sector partnership.

Healthcare workforce

Suggested geography: Yuba-Sutter regional healthcare market

What the latest review found: Yuba College has a real multi-provider nursing clinical network, including Adventist Health Rideout and other regional clinical partners, and participates in collaborative clinical-assignment and onboarding work.

Why that does not clear the gate: The current nursing handbook reports adequate clinical placement. The clinical network is useful workforce infrastructure, but it does not document a present shared provider bottleneck. The broader healthcare collaborative also remains focused mainly on access, telehealth and health outcomes.

Reopen when: At least two Yuba-Sutter providers jointly define and own one shortage, retention, advancement or clinical-capacity problem.
